# File structure

This guide covers the maintained source and data files. Generated build output, dependencies, caches, and local exports are omitted.

```text
.
├── .agents/skills/monthly-electricity-data/
│   └── SKILL.md                 Monthly meter and spot-price refresh workflow
├── .openai/
│   └── hosting.json             Sites/Cloudflare project configuration
├── .github/workflows/
│   └── pages.yml                GitHub Pages build and deployment
├── app/
│   ├── page.tsx                 Usage dashboard and browser-side analysis
│   ├── cost-comparison.tsx      Tariff and settled spot-price comparison
│   ├── layout.tsx               App metadata and document shell
│   └── globals.css              Shared dashboard styling
├── build/
│   └── sites-vite-plugin.ts     Sites preview integration for local app development
├── data/
│   ├── Electricty Data ...csv   Historical meter exports
│   └── wilton_settled_spot_prices_since_2024.csv
│                               Collated official WIL0331 settled prices
├── db/
│   ├── index.ts                 Optional Cloudflare D1 access helper
│   └── schema.ts                Empty Drizzle schema placeholder
├── docs/                        Architecture, file structure, and deployment guides
├── drizzle/                      Drizzle migration metadata
├── examples/d1/                  Optional D1 example schema and route
├── public/
│   ├── electricity-data.json    Processed anonymized meter intervals
│   └── spot-price-data.json     Processed WIL0331 spot-price intervals
├── scripts/
│   ├── process-electricity-data.mjs
│   ├── update-spot-price-source.mjs
│   └── process-spot-price-data.mjs
├── src/
│   └── pages-main.tsx           Static Vite entry; mounts app/page.tsx
├── tests/
│   ├── rendered-html.test.mjs   Server-rendered app checks
│   └── spot-data.test.mjs       Spot-price format and coverage checks
├── worker/
│   └── index.ts                 Cloudflare Worker entry point for Vinext development
├── index.html                   Static Vite HTML shell
├── package.json                Commands and dependencies
├── package-lock.json           Locked npm dependency versions
├── drizzle.config.ts           Drizzle Kit configuration
├── vite.config.ts              Vinext and Cloudflare development configuration
├── next.config.ts              Next-compatible configuration
└── vite.pages.config.ts        Static GitHub Pages build configuration
```

## Local and generated files

- Monthly smart-meter exports are expected under `data/`, but matching raw exports are Git-ignored because they include supply-point and device identifiers. Commit the anonymized JSON output, not those source exports.
- `dist-pages/` is generated by `npm run build:pages` and uploaded by GitHub Actions.
- `node_modules/`, `.wrangler/`, `.vinext/`, and other caches/build directories are local or generated state.
- `.openai/hosting.json` and `worker/` support the Cloudflare/Sites development setup. They are not used by the GitHub Pages deployment path.
